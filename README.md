# Shuran Zheng Personal Homepage

This is a lightweight static homepage designed for GitHub Pages.

## Publish on GitHub Pages

1. Create a repository named `<your-github-username>.github.io` for a personal site, or use any repository for a project site.
2. Commit `index.html`, `publications.html`, `teaching.html`, `advising.html`, `styles.css`, `assets/`, and `files/`.
3. In GitHub, open the repository settings, go to Pages, and publish from the `main` branch root.
4. Your homepage will appear at `https://<your-github-username>.github.io/`.
5. The slides file will be public at `https://<your-github-username>.github.io/files/explaining-data-mixing-scaling-laws-slides.pdf`.

## Update Content

- Edit `index.html`, `publications.html`, `teaching.html`, and `advising.html` to update site content.
- Replace `assets/profile-900.jpg` if you want a different portrait.
- Replace files in `files/` when updating locally hosted slides or papers.
- Keep links relative so the site works both locally and on GitHub Pages.
